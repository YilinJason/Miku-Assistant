## Phase A scope and chosen design

Reported failure is while quiet and assistant silent. First fix acoustic input admission, not speaker identification. Echo timing phase B is deferred until A reviewed and checked. Do not rewrite whole STT/CLI/Paraformer architecture or alter RVC, TTS, model assets, resource settings, permissions or memory data.

1. Implement a small stdlib-only settings + acoustic guard module (e.g. src/voice/input_audio.py). Imports must not touch audio devices, native VAD, models or spawn tasks. Strictly validate config before assembly side effects, while preserving direct STTEngine/provider callers. Suggested namespace voice.stt.input_audio: enabled true, energy_floor 300, energy_ceiling 12000 (initial threshold clamped inside these); vad_mode 2, min_voiced_ms 180, min_consecutive_ms 90, min_voiced_ratio 0.12. Frame size fixed 30ms at 16kHz mono signed16 PCM. Settings must reject bool-as-int, nonfinite, out-of-bounds, contradictory thresholds, wrong shape and unknown keys. Thresholds documented as provisional, not guaranteed user accuracy. Keep parameter count small; maintain existing energy_threshold initial setting and other engine compatibility. Optional voice.stt.microphone_device_index defaults null; validate a real nonnegative bounded int or None. Explicit invalid/unavailable device errors; no fallback to different device.

2. Fix dynamic threshold drift for the default Paraformer capture path. Use a small bounded Recognizer adapter/subclass factory so every assignment by SpeechRecognition calibration/_listen remains within configured floor/ceiling, not just once before listen. No third-party package patch/monkeypatch. Do not globally freeze at 2000 and make quiet speech unreachable. Keep legacy engines' existing semantics unless guard explicitly configured; document default Paraformer scope. Handle SR.__init__ assigning energy_threshold before custom state and fake recognizers in existing tests. Calibration must use configured floor instead of old hardcoded configured_threshold*0.5. No new calibration threads.

3. Local VAD using pinned webrtcvad-wheels==2.0.14.post1 in main requirements (official upstream https://github.com/daanzu/py-webrtcvad-wheels ; Windows CPython3.12 binary wheel supported; fixed native allocation leak versions >=2.0.13). No neural models/torch/new subprocess/GPU/download code. Lazy native import; guard unavailable fails closed with an actionable install hint at preflight/recognize, NEVER silently accepts noise. Text/provider-only paths remain lightweight and independent. Disabled guard is explicit compatibility option, not automatic fallback. Scope to real default Paraformer microphone capture; direct PCM diagnostic API and injected providers keep documented existing contract.

4. Reject invalid/empty/misaligned/oversized (>15s /480000 bytes at 16kHz mono16)/zero PCM before ASR. Analyze only a bounded buffer. Treat last partial frame deterministically (ignore or zero-pad with documented accounting); do not count invented padding as real voiced duration. Use both total voiced ms, longest consecutive run and voiced ratio. WebRTC state must not leak from one utterance/session into the next; use cheap per-utterance native state reset (not a model worker). Return structured verdict with reason and useful aggregate metrics. No transcript blacklists, confidence invention or speaker claims. Rejects return UNRECOGNIZED, unavailable/native errors NOT_READY or SERVICE_ERROR with a stable safe hint; cancellation/closed state takes precedence. Conversion to 16k PCM should occur once for guarded real Paraformer microphone path then be passed to transcribe; preserve existing method callers. Do not spawn Paraformer just to reject non-speech. Guard+native module readiness can be checked without opening a mic or spawning worker.

5. Wire validated settings through src/core/assembly.py and STTEngine; keep fake factories/provider compatibility. Microphone device choice used consistently for check_microphone and real capture. Device list/default identity diagnostic may occur in existing explicit microphone checks, not constructor/text mode. Log safe counters/duration/reason at bounded frequency/appropriate level, no saved PCM/transcripts/speaker biometrics. Do not add per-utterance INFO spam for quiet input.

6. Add meaningful fake/offline tests for internal SR assignments below floor and above ceiling, strict config early rejection, VAD silence/noise verdicts, positive short normal/quiet voiced fixtures with fake per-frame decisions, frame boundary/accounting, no backend retained state, disabled/unavailable/native error/cancel/close, rejected audio never calls Paraformer and never dispatches to assistant/LLM/memory/tool, explicit mic selection and invalid device.
