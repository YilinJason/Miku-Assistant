1. **P1 asset trust bypass**: resolve_silero_asset_path resolves before validation, then validate checks resolved.is_symlink (always false for a followed symlink). Cache key contains path/size/expected hash but no file identity/mtime, so a same-size mutation after first validation is accepted by a NEW adapter instance. Also passing the path to ORT reopens it after hashing (TOCTOU). Prefer simpler immutable bytes: inspect lexical fixed path/parents for symlink/reparse boundary, bounded-read exactly expected_size plus reject overflow, verify SHA256, pass the VERIFIED bytes object to InferenceSession, not reopened path. No global success cache needed (2.3MB read once per new model instance); existing loaded immutable model can be reused. Fake session_factory receives verified model bytes. Remove redundant cache/reset API if no longer needed. Preserve fixed canonical repo asset and no user-configurable path. 2. **P1 close/cancel race / indefinite waits**: close currently only sets _closed after acquiring full-inference lock; it can block forever and last-frame cancellation isn't checked before success. Introduce closing event set BEFORE waiting; check it/caller cancel before/after load, after EACH run and before returning success. Bound lock acquisition for close(timeout/budget), returning False and retaining session when active native call hasn't stopped; no worker threads to hide the wait, no releasing native session underneath active run. Subsequent close retry must release correctly. New score during closing rejects; concurrent score/load either bounded wait or explicit busy (document). Add deterministic event/barrier tests for last-frame cancel, last-frame close request, load close, close timeout/retained session then retry, and multi-caller single-session creation. Tests must join threads and surface exceptions, no sleeps as race oracle.

Fake nodes currently omit types/shapes; improve fixtures, test wrong scalar sr type, state rank/shape/type, extra/missing nodes and invalid providers.

Invalid native output type/None/len/shape must return stable error, never escape exception or boolean/integer interpreted as human speech. Do not catch BaseException. Add fake output None, wrong lengths/dtypes/shapes/object-state/NaN, no raw data/path leakage.
