## Required corrections (one coherent lifecycle fix, not cosmetic patches)

1. **P1 functional PCM bound** — `protocol.py:MAX_JSON_LINE_CHARS=16384` rejects even one second (32000 PCM bytes -> ~42700 base64 chars), despite allowing 15 seconds. Separate bounded inbound audio JSON size (~640KiB + fixed envelope) and outbound transcription JSON size. Test 1s, exact 15s, oversized and truncated lines. Strict schema int (bool is not version), PCM bytes nonempty/even, request ID geometry, finite settings including direct dataclass construction; exact allowed keys/status text invariants. Worker must reject wrong schema rather than merely checking req.
2. **P1 Windows / capability options** — `worker_env.py` tests forward-slash MODEL_DIR_REL against backslash Path string, so fixed Windows layout always fails. Compare canonical fixed Paths with reparse protections, not substrings. Fixed Popen must set cwd, shell=False, UTF-8 encoding/errors, PYTHONUTF8, and reject ALL caller kwargs (current unknown creationflags/startupinfo can pass). Validate exact LocalAsrWorkerLaunch + ParaformerSettings types and parent identity before spawn on all branches.
3. **P1 worker ownership and shutdown** — `client._retire_worker` drops `_proc` immediately after terminate, `_drain_close` discards proc/reader/writer regardless of join/poll and then reports success by checking the cleared field. This loses a live model tree and blocked I/O. Never discard until strict actual Job quiescence and both actual I/O joins. Retain incomplete state, prevent restart, permit later close retry; handle `take_owned_worker_from_exception` on failed spawn. Stage proc/reader/writer transactionally and recover partial start failure. Terminate the Job before attempting stream operations owned by blocked I/O; bounded close must not synchronously hang on TextIO locks. Kill request is not confirmation of exit.
4. **P1 locking / deadlines / state** — shutdown waits unbounded on request lock; transcribe likewise queues behind it, making busy check ineffective. Use nonblocking single-inflight admission, short-held lifecycle state lock, closing Event set before any wait, bounded retirement serialization. Mark even unused-client shutdown terminal. Startup and inference deadlines are separate: current inference deadline starts BEFORE cold loading and expires during normal startup. PCM validation before launch; no late SUCCESS after caller cancel or shutdown, no stale/wrong-id acceptance; reader fatal/error/EOF fails promptly. Closing/startup race cannot publish a new worker after shutdown reports success; no spawn if old owner is incomplete. No cancel/shutdown write adds an extra unbudgeted 0.5s.
5. **P1 STT ownership** — shutdown must permanently close the wrapper, including legacy/provider branches; strict True, not bool(closer()). New client creation races with shutdown and recording. One engine-level operation admitted at a time; close signals cancellation and returns incomplete while recording still owns mic/engine, does not create another worker or release shared TFM. Validate finite timeout and phrase limits BEFORE opening mic (bool/NaN/Inf/nonpositive invalid); cap Paraformer recording to 15s. New path must not detach ambient-noise thread and close/reuse source underneath it. Existing provider/no-resource compatibility retained. Close engine-owned TFM only when quiet; never shared one. Assistant/unpublished/rollback completion must include this status, not drop refs.
6. **P1 startup network guard** — replacing socket.socket CLASS with a FUNCTION before torch/funasr imports can break ssl/asyncio subclasses during normal imports. Preserve socket type; block outbound connects/DNS/create_connection with a tested guard, runtime flags plus guarded import/inference. `torch.set_num_interop_threads(1)` must actually execute, env TORCH_NUM_INTEROP_THREADS alone is ineffective. Explicit CPU dtype and inference_mode. Do not silently truncate/str-coerce malformed model result into valid text.
7. **P1 trusted assets** — current locally written manifest is its own trust anchor; known revision string plus regenerated hashes can bless arbitrary bytes. Bind model.pt to official LFS SHA256 `5bba782a5e9196166233b9ab12ba04cadff9ef9212b4ff6153ed9290ff679025`; remaining files to official pinned Git blob IDs in `tmp/paraformer-hf-official-metadata-20261105.json` (or reviewed immutable SHA256 constants computed from verified upstream blobs). Check every path component for junction/reparse escape including model dir, manifest and interpreter before capture/load, using existing path_trust. Reject OmegaConf interpolation and config/JSON overrides that refer outside fixed assets or enable remote/custom models. `TORCH_FORCE_WEIGHTS_ONLY_LOAD=1` with CPU torch 2.6 avoids unrestricted pickle fallback. No blanket unsafe torch.load workaround.
