## 启动（PowerShell，MAIN Python 3.12）

每次新开终端先进入仓库，再用 **同一解释器** 启动（无需 `activate.ps1` 或执行策略改动）：

```powershell
Set-Location 'D:\Miku_Assistant_LLM'
& 'C:\Users\uitra\AppData\Local\Programs\Python\Python312\python.exe' -X utf8 .\main.py --config .\tmp\manual-voice-test-20261105\config.yaml --mode voice
```

- 该隔离配置已存在，使用 Paraformer；缺省的 `voice.stt.input_audio.*` 使用新默认值（含 `capture_mode: continuous`）。测试记忆库位于 `tmp`，与正式记忆库隔离。
- **不要** 同时开两个上述实例；若需重测，先正常退出当前会话（见下），再执行同一条启动命令。
- 交互模式口令：**开启语音模式** / **关闭语音模式**（或界面等效操作）。若某次启动在 `--mode voice` 下整程序退出，**重新运行上条命令** 即可再次进入。

## Utterance 对照（可选）

需要对照原先的逐句录音时，在同一隔离配置中设置以下字段，保存后完全退出助手再重启。正常测试保留默认的 `continuous`。

```yaml
voice:
  stt:
    input_audio:
      capture_mode: utterance
```

只合并这个字段，保留配置中其他已有内容。

## 阶段 A — 安静与操作噪声（约 2 分钟，建议耳机）

1. 进入语音模式后保持 **约 2 分钟** 安静，记录误触发（风扇、键盘轻敲可穿插）。
2. 正常音量与偏软短中文句各若干次（每句 <5 s）。
3. **连续三问**：第一句仍在解码/播报时连问第二、第三句，观察插话是否合理（转写级门控，非 AEC）。
4. 使用 **关闭语音模式**（或停止口令）正常退出；记下 `unsafe_pause` / 采集错误提示（若有）。
5. 如果回到助手的文本输入界面，输入 **开启语音模式** 重入，不另开进程。如果助手已关闭并回到 PowerShell 提示符，再执行一次启动命令。重复三次开启/关闭，观察麦克风是否按模式停止及是否出现卡顿。

## 阶段 B — 扬声器（可选）

摘耳机、低音量外放，重复简短问答。当前实现 **无** 声学 AEC，外放回声仍可能穿透转写门控；可与耳机段对比记录。
