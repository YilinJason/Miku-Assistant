## 阻断项：候选事实只验证了已解析片段，未验证内容可随合法片段入库

`src/memory/provenance.py::fact_supported_by_evidence()` 会收集能够解析的谓词，只要这些谓词匹配就返回 `True`。候选中的其他子句、并列内容或修饰语没有被要求成功解析，也没有被证明来自用户证据。

Codex 已离线复现以下错误结果全部为 `True`：

```text
user="我叫林小舟"
fact="用户叫林小舟，最喜欢抹茶拿铁"
quote="我叫林小舟"

user="我喜欢抹茶拿铁"
fact="用户喜欢抹茶拿铁，少糖多奶"
quote="我喜欢抹茶拿铁"

user="我叫林小舟，住在青禾市"
fact="用户叫林小舟，住在纽约"
quote="我叫林小舟，住在青禾市"

user="我喜欢乌龙茶"
fact="用户喜欢乌龙茶并住在纽约"
quote="我喜欢乌龙茶"
```

这仍允许模型把用户没有说过的饮品、甜度、奶量或住址写入 `MODEL_INFERRED`，与本轮“用户原文是唯一事实来源”的目标冲突。
