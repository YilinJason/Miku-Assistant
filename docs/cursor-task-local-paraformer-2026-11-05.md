- Reuse host_memory admission, add Paraformer thresholds separately (4096 MiB physical, 4096 MiB commit initially; fail closed if unobservable on Windows). No reductions to existing RVC/Cosy thresholds. Do not launch worker if missing/invalid assets or permission denied. Asset errors give actionable setup hint without sensitive text/path logs.
- JSONL protocol version 1. Max utterance 15 seconds of 16 kHz mono PCM signed16LE, bounded base64 payload; no arbitrary file path from worker requests. Strict types/status/request IDs; limit output text 4096 chars and stdout line/queue. Startup deadline max 45s, inference max 15s, close budget 2s, strict finite settings. Single monotonic deadline within each operation, bounded lock waits, cancelled/late/mismatched/malformed output is never SUCCESS. CANCELLED and timeout retire the worker so no stale response crosses turns; no automatic retry storm. If an operation is in progress, shutdown signals it before bounded waiting. Never free/restart an unconfirmed live owner. Retain process/I/O references on incomplete close and allow later retry. Constructor and import do not open mic or import torch/model; lazy worker start on first transcription acceptable, document first-use cold latency.
- Worker FunASR fixed local paths, device='cpu', ncpu=..., disable_update=True, disable_pbar=True, trust_remote_code=False; redirect third-party stdout away from protocol, torch.inference_mode, no inference cache/history. Refuse unsafe config interpolation/remote asset references. Use official file config semantics; do not claim model hotword support. Socket/network guard in worker should reject runtime network use instead of silently relying solely on offline env flags.
